# Aiohttp

Example [Aiohttp](https://docs.aiohttp.org/) app. Aiohttp is an asynchronous HTTP client and server framework for Python, built on asyncio.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `8000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
pip3 install -r requirements.txt

# start the app
python3 main.py
```
